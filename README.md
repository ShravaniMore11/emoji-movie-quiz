# 🎬 Emoji Movie Quiz

An interactive movie-guessing game built using HTML, CSS, and JavaScript. The game challenges players to identify movies by interpreting emoji clues, making movie guessing fun and engaging.

## 🎮 Play the Game

**Play online:** [Emoji Movie Quiz](https://shravanimore11.github.io/emoji-movie-quiz/)

## 📌 Project Overview

Emoji Movie Quiz is a mini web development project that combines emojis and movie knowledge into an interactive guessing game. Players use the emoji clues provided on the screen to identify the correct movie and progress through the quiz.

The project was created to practise front-end web development and explore how JavaScript can make a webpage interactive.

## ✨ Features

- **Interactive Welcome Screen:** Introduces players to the game.
- **Emoji-Based Movie Clues:** Guess movie titles from emoji combinations.
- **Answer Interaction:** Select or submit answers according to the game's interface.
- **Score Tracking:** Track performance during the quiz, if enabled in the game.
- **Results Screen:** View the outcome after completing the quiz.
- **Interactive User Interface:** Navigate between game screens and interact with the quiz.

## 🛠️ Technologies Used

- **HTML5:** Structures the webpage and game screens.
- **CSS3:** Styles the interface, layouts, and visual elements.
- **JavaScript:** Implements game logic, user interactions, answer checking, and screen transitions.

## 💻 Development Tools and Platform

- **Code Editor:** Visual Studio Code
- **Version Control and Repository Hosting:** GitHub
- **Website Deployment:** GitHub Pages
- **Browser:** Google Chrome (for testing)

## 🕹️ How to Play

1. Open the game using the live website link above.
2. Start the quiz from the welcome screen.
3. Observe the emoji clues displayed for each movie.
4. Identify the movie and submit or select your answer.
5. Continue through the questions and view your final result.
